# auto-excel-report
Автоматизированная генерация аналитических отчётов по продажам: сводные таблицы, графики и красиво оформленный Excel-отчёт.

## Цель проекта
Автоматизировать рутину подготовки еженедельного отчёта по продажам, чтобы сократить время с 2+ часов до 2 минут и исключить ошибки ручного ввода.

## Возможности
- Чтение сырых данных из CSV (`data/sales_raw.csv`)
- Агрегация по регионам, категориям и месяцам (pandas)
- Построение 3 графиков (matplotlib)
- Генерация Excel-отчёта с форматированием (openpyxl)
- Логирование всех шагов и предупреждений о проблемах в данных
- Проверка занятости файла (защита от перезаписи открытого Excel)
- Имя файла с датой (история отчётов)
